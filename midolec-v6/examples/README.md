# Midolec V6 Examples

This folder contains small text files that users can process after installing
the runtime dependencies.

Generated `.json` files in this folder are ignored by Git.

Example commands from `midolec-v6/`:

```bash
./midolec-v6 examples/es/legal_cross_references.txt examples/es/legal_cross_references.json
./midolec-v6 -L en examples/en/plain_language_terms.txt examples/en/plain_language_terms.json
```
