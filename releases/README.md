# Releases

## English
This folder documents the packaging policy. The actual binaries and
large files should be uploaded to GitHub Releases as versioned assets.

Do not upload executables, `.so` libraries, spaCy models or FreeLing resources here.

## Spanish
Esta carpeta documenta la politica de empaquetado. Los binarios reales y
archivos pesados deben subirse a GitHub Releases como assets versionados.

No subas aqui ejecutables, librerias `.so`, modelos spaCy ni recursos FreeLing.
