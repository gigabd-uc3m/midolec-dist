# Midolec Examples

This folder contains small text files that users can process after installing
the runtime dependencies.

Generated `.json` files in this folder are ignored by Git.

Example commands from `midolec-v6/`:

```bash
./midolec-v6 ../examples/es/legal_cross_references.txt
./midolec-v6 -L en ../examples/en/plain_language_terms.txt
```

Midolec creates the `.json` output next to the input file when no explicit
output path is provided.
