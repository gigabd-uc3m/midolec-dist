# Security Policy

We take security and privacy seriously. Please report suspected vulnerabilities
responsibly so we can triage and fix them without exposing users.

## Supported Versions

We provide security support for the following Midolec distribution versions:

| Version | Supported |
| --- | --- |
| v6 | Yes |
| v4.2 | Yes |
| Older versions | No |

We recommend using the latest supported distribution whenever possible. Older
versions may not receive fixes.

## Reporting A Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Email the maintainers with:

- A clear description of the issue.
- Steps to reproduce it.
- The expected impact.
- Platform details, including operating system, Midolec version, and relevant
  configuration.
- Any logs or screenshots that help reproduce the issue.

Contact:

[gigabd@uc3m.es](mailto:gigabd@uc3m.es?subject=%5Bmidolec-dist%5D%5Bsecurity%5D)

Use this subject prefix:

```text
[midolec-dist] [security]
```

## What To Expect

We will acknowledge your report as soon as possible, typically within five
business days.

We will keep you updated on our assessment and any fix or mitigation.

We will credit you in security advisories and release notes unless you prefer
to remain anonymous.
